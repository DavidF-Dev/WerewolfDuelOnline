Werewolf: Duel! Online — screen mockups

Low-fidelity layouts for discussion, using placeholder shapes. Human cards are rounded shields with a solid border; Werewolf cards are notched and hatched, so the two factions differ in shape and pattern as well as colour. The large number is the initiative. Palette is Okabe–Ito. The default "Moonlit" theme adds a night-sky header with a moon emblem, warm parchment panels, and a faint treeline-and-village silhouette at the bottom of each screen. All of these are decorative, hidden from screen readers, and come from the theme pack. Use the button to switch between light and dark.

Not shown here: the Join screen (enter code / scan QR), the log and rules drawer, the replay viewer, the Backup screen, the Clear history confirmation and the tutorial. They reuse the same components.
